Vision-Guided Machine Tending

Three-robot CNC tending system for multi-operation bone screw manufacturing.

NDA-safe summary of a robotic cell with three robots tending three CNC lathes across sequential operations, using hierarchical robot state machines, safety integration, pneumatics, and inspection.

System Snapshot

Industry
Medical manufacturing
Application
CNC machine tending
Robots
Three FANUC robots
Process
Three sequential operations
Core challenge
Coordinated tending, state control, recovery, and inspection

Problem

The cell needed to automate a multi-operation CNC process while managing part flow, machine availability, safety states, and inspection logic across multiple robots and lathes.

Architecture

  • Three robots coordinated with three CNC machines across sequential operations.
  • Robot-side hierarchical state machines handled process flow, recovery, and machine interaction.
  • PLC integration managed critical signals, permissives, interlocks, and cell-level behavior.
  • Safety systems and pneumatics were integrated into the machine tending process.
  • Inspection logic supported process validation before downstream operations.

Contribution

Owned end-to-end project development across design, programming, integration, commissioning, troubleshooting, customer support, documentation, and training.

Engineering Judgment

The highest-value work was not a single program or component. It was structuring the cell so each robot could make reliable decisions, recover predictably, and stay coordinated with the CNC process without hiding failure modes from operators or maintenance teams.
